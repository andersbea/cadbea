# Examples

Examples are runnable consumers of the local `cadbea` library and integration
fixtures for its development. Each example owns its model and hardware notes;
generic viewing, capture, and validation behavior belongs in the library.

- [GC CAD enclosure](gc-cad/README.md): a work-in-progress Replicad enclosure
  with printable parts, hardware references, exploded and section states.

Install the root dependencies before an example's dependencies. Run examples
from this checkout; the `cadbea` dependency links back to the repository root.
